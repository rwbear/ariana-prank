# Ariana prank site

Mobile-first, single-file, zero dependencies. Tap the photo to show the next one.

## Add photos
Put images in `images/` named `1.jpg`, `2.jpg`, `3.jpg`... (jpg/jpeg/png/webp, no gaps in numbering).
Tip: resize to ~1200px on the long side (under 300 KB each) so it loads instantly.

## Publish
Settings -> Pages -> Deploy from branch -> `main` / root.
Site: https://rwbear.github.io/ariana-prank/
